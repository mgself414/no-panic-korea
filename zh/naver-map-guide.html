① 本手册阅读方法 — 屏幕标记规则

本文同样采用与#1270自助点餐机篇相同的标记规则。不是写"要用Naver地图"，而是原样记录"屏幕上会出现什么、要按哪个按钮"。

  • 屏幕上的按钮用方括号标注：Directions
  • 屏幕标题·提示文字用「」标注：「路线查询 (gilchatgi 길찾기)」
  • 用手完成的动作用加粗标注："点击顶部搜索栏"

② 为什么不是谷歌地图而是Naver地图

韩国出于安全法规限制，精密地图数据禁止向海外传出，所以谷歌地图只能做部分汽车导航，大众交通·步行路线基本无法使用。相比之下，Naver地图(Kakao地图水平相当)拥有地铁·公交实时数据和步行捷径，是国内路线查询的唯一权威来源。数字基础设施整体结构可参考#080到达必备篇 — 记住结论就够了：在韩国查路线，用Naver。

③ 切换成英文 — 3步骤

App第一次打开全是韩文。首先要做的事：

1. 点击左上角或底部☰ 菜单 (메뉴)

2. 点击设置 (Settings/설정)

3. 语言 (Language/언어) → 选择English

无需重启，整个屏幕立即变成英文。之后本文所有画面都以英文版为准。

④ 搜索技巧 — 打不出韩文店名时

  • 顶部搜索栏直接输入英文罗马拼音也能识别("Gyeongbokgung"、"Myeongdong")。
  • 不知道店名时，用英文类别词搜索突破：输入coffee、convenience store、pharmacy这样的普通名词，附近候选就会以列表形式出现。
  • 在候选列表里看距离·评分，点击其中一个 → 跳转到详情画面。

⑤ 路线查询主流程 — 4步骤

1. 在目的地详情画面点击蓝色Directions按钮

2. 顶部标签并排显示4种出行方式：🚗 Car 🚇 Public Transit 🚶 Walk 🚴 Bike — 点击切换

3. 所选方式的路线候选以列表形式出现(按所需时间排序)

4. 点击想要的路线 → 进入逐步导航详情画面

⑥ 结果画面读法 — 出口号码是关键信息

第一次用地图App的人最容易搞混的地方就在这里。把画面构成原样搬过来：

```

🚇 34分钟 · 换乘2次 · ₩1,500

① 江南站 (Gangnam-yeok / 강남역) [ 3号出口 (3번 출구) ] 方向步行3分钟

↓ 乘坐新盆唐线 (Sinbundang Line / 신분당선) · 下一班列车4分钟后 · 4站

② 新论岘站 (Sinnonhyeon-yeok / 신논현역) 下车 → [ 2号出口 (2번 출구) ]

↓ 步行5分钟

🏁 到达

```

  • 大众交通=地铁+公交整合：同一条路线里地铁和公交会混在一起出现。每次换乘画面都会提示。
  • 出口号码：读不懂车站名字也没关系。像3号出口一样只看数字找到对应号码就行 — 这是这款App里最重要的信息。
  • 等待时间：以"下一班列车4分钟后"这样按分钟显示。
  • 站数："4 stops"会数出需要坐几站后下车。
  • 步行模式会抓取地下通道·穿楼捷径 — 比起绕地面大圈的路线，往往是实际的最短距离。

⑦ 无障碍(避开楼梯)模式 — 拉行李箱·高龄旅行者必备

2025年8月起，大众交通路线新增了避开楼梯 (계단 제외)选项。打开后地图上会标出电梯位置，路线本身也会重新计算成经过电梯的路径。拖着行李箱移动，或对爬楼梯有负担的高龄旅行者，出发前务必先打开这个选项。

⑧ 保存·分享 & 生存词10个

  • 结果画面顶部心形/收藏图标 → 保存到收藏夹，之后从菜单直接调出。
  • 分享图标 → 通过KakaoTalk·短信发送路线链接。收到的人就算没装App，也能直接用网页打开。

即使切换成英文，实际的地铁·公交标牌上依然保留韩文。用来对照画面术语和标牌的生存词：

⑨ 慌张场景3种

1. 和谷歌地图结果不一样 — 属于正常现象。如②所说，韩国的大众交通·步行数据谷歌地图本来就没有。请相信Naver地图的结果。

2. 搜索结果0条 — 大概率是罗马拼音写法差异导致("Gwanghwamun"和"Kwanghwamun"这类拼写偏差)。可以缩短拼写重新输入，或用④的类别搜索绕过。

3. GPS漂移 — 在高层建筑密集区或地下，定位像瞬移一样跳动是常见现象。走几步再重新确认画面就能定住。

⑩ 备用方案 — Naver地图打不开的话

  • Kakao地图 (Kakao Map / 카카오맵)：数据覆盖率几乎同等水平。结果看起来不对时，用Kakao地图再搜一次交叉核对。
  • Papago镜头：不是地图App本身而是标牌·指示牌看不懂时 — 用相机对准即可实时翻译。App设置参考#1230必备App篇。
