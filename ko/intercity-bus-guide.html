🎯 이 글을 읽는 법 — 화면 표기 규약

화면 표기 규약은 #1270에서 정한 것을 그대로 쓴다.

  • 화면 속 버튼은 대괄호: 결제하기
  • 화면 제목·안내 문구는 낫표: 「목적지 검색」
  • 손으로 하는 동작은 굵게: 표를 기사에게 직접 제시

이 글은 KTX가 닿지 않는 중소도시로 갈 때 — 즉 #1287(KTX)과 짝이 되는 편이다. 교통수단 전체 비교·요금 개요는 #239를 먼저 보자. 여기는 예매 화면부터 버스에 타기까지만 다룬다.

① 고속 vs 시외 — 가장 큰 함정은 "앱이 아예 다르다"

한국은 "버스터미널"이 하나의 통합 시스템이 아니다. 고속버스와 시외버스는 법적으로도, 예매 앱도, 운영사도 별개다. KTX의 코레일톡 같은 단일 앱이 없다 — 이걸 모르고 아무 앱이나 깔면 "내가 가려는 노선이 검색에 안 뜬다"는 상황을 그대로 겪는다.

구분 고속버스 (Express) 시외버스 (Intercity)
주로 연결하는 곳 대도시 간 직행 (서울↔부산·대전·광주 등) 중소도시 경유 (읍·면 단위 정류장 포함)
예매 앱/사이트 kobus.co.kr · 고속버스티머니 앱 Bustago (bustago.or.kr) · TxBus 앱
정차 방식 무정차에 가까움 중간 정류장 여러 곳 경유(내가 탈 버스가 서는지 미리 확인)
좌석 등급 일반·우등·프리미엄 3종 다 있음 일반·우등 위주(프리미엄은 드묾)

핵심: 목적지를 검색했는데 안 뜨면 "노선이 없다"가 아니라 다른 앱을 열어야 한다는 신호다. 대도시행이면 kobus, 소도시·경유지면 Bustago부터 검색한다.

등급 배치 특징

② 예매 4루트 — 어디서, 어떻게 사나

방법 어디서 해외카드 비고
공식 웹 kobus.co.kr / bustago.or.kr — 영어·일본어·중국어 지원 거절 빈도 있음(VAN 인프라 특성, #527 참고) 노선·시간표 먼저 확인하기 좋음
앱 고속버스티머니 / TxBus 마찬가지로 거절될 수 있음 한국어 UI 위주, 미리 깔아도 화면 자체는 낯설 수 있음
터미널 창구(매표소) 각 터미널 매표소 현금·대부분 카드 OK 가장 확실한 루트, 목적지를 말로 못 해도 보여주면 됨
발권기 터미널 로비 무인기 기계마다 다름 ③ 화면 플로우 참고

해외카드가 웹·앱에서 계속 거절될 때: Klook에서 노선을 검색해 먼저 결제한다(해외카드 통과율이 훨씬 높다). 예매 확정 후 QR 바우처를 받는데, 이 QR을 터미널 창구·발권기에서 실물 승차권으로 교환해야 하는 노선이 많다 — QR 화면만으로 바로 승차되는 경우도 있으니, 확정 문자·이메일에 "교환 필요" 안내가 있는지 확인한다.

③ 발권기 화면 플로우 — 화면 그대로

무인 발권기는 대체로 아래 순서다.

1. 「고속버스 / 시외버스」 선택 — 여기서부터 갈린다, 잘못 고르면 원하는 노선이 안 나옴

2. 「출발지 → 도착지」 검색 화면 — 도착지를 한글 또는 영문으로 입력

3. 「날짜·시간」 선택 → 시간표 목록에서 원하는 편 터치

4. 「좌석 등급」 일반 우등 프리미엄 중 선택

5. 「좌석 배치도」에서 자리 직접 터치

6. 「결제 수단」 → 카드 삽입 또는 현금 투입

7. 발권 → 표(또는 QR 인쇄) 출력, 승차홈 번호가 같이 찍히는 기계도 있음

옵션 화면에서 멈췄다면 대부분 화면 하단의 확인 또는 다음을 못 눌러서다.

④ 터미널 현장 플로우 — 표를 들고 버스에 앉기까지

1. 대기실 진입 → 전광판에서 내 버스 확인: 버스 번호(또는 목적지·출발시각)와 나란히 승차홈(플랫폼) 번호가 뜬다

2. 출발 5~10분 전 해당 승차홈으로 이동 — 미리 가 있어도 되지만, 버스가 늦게 배정 홈에 붙는 경우가 있어 전광판을 한 번 더 확인

3. 승차홈에서 대기 중인 기사에게 표 또는 QR을 직접 제시

4. 큰 캐리어는 버스 옆면 짐칸에 기사가 넣어준다 — 짐표(스티커)를 주는 경우 하차 시 대조하니 보관

승차홈 번호가 예매 단계에서 미리 안 뜨는 경우가 많다는 점이 KTX(#1287, 출발 15분 전 공개)와 같은 구조다. 전광판을 못 찾겠으면 대기실 중앙 안내데스크 근처가 보통 가장 잘 보이는 위치다.

⑤ 온라인으로 예매했는데 왜 창구에서 표를 또 뽑나

고속버스(kobus·티머니)는 예매 확정 화면(모바일 QR)이 그대로 승차권인 경우가 많다. 반면 시외버스(Bustago·TxBus)는 예매번호만 발급되고, 터미널 발권기에 예매번호(또는 생년월일)를 입력해 실물 승차권을 뽑아야 기사가 인정하는 노선이 적지 않다. 이것도 결국 ①의 "앱이 다르다" 문제의 연장선 — 시외버스 노선을 예매했다면 출발 20~30분 전 도착해 발권기부터 들르는 걸 기본값으로 삼자.

⑦ 당황 시나리오 3

1. 예매했는데 내 노선이 앱에 없다 — 잘못된 앱이다. 고속버스 앱(kobus·티머니)에서 안 보이면 Bustago·TxBus로 바꿔 검색한다. ①표를 다시 보면 1분 안에 해결.

2. 승차홈을 못 찾겠다 — 전광판이 안 보이면 안내데스크나 매표소 창구에 표를 보여주며 "몇 번이에요?"만 물어도 손가락으로 알려준다.

3. 버스를 놓쳤다 — 고속버스는 배차 간격이 짧은 노선(서울↔부산 등)이면 다음 편 대기표로 전환 가능한 창구가 많다. 시외버스는 배차가 뜸한 노선도 있으니 놓친 즉시 매표소로 가서 다음 편·환불을 바로 확인한다.

⑧ 플랜B — 그래도 막히면

앱·웹이 계속 막히면 창구로 간다 — 이게 가장 확실하다. 목적지 이름을 말로 못 해도 지도 앱이나 메모에 적은 지명을 보여주면 매표소 직원이 알아서 맞는 표를 찾아준다. 카드가 거절돼도 창구는 대부분 다른 카드나 현금 결제가 즉시 가능하다.
