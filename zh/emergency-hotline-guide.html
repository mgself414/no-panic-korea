🎯 本指南阅读方法 — 标记规则

韩国是个安全的国家，但记住一个号码会让人安心不少。这篇只专注讲这一个号码。

  • 拨号按钮用方括号：1 ] [ 3 ] [ 3 ] [ 0
  • 客服·机构的应答用「」标注：「这里是Korea Travel Hotline」
  • 用手完成的动作用加粗标注：调成扬声器模式递过去
  • 要原样展示的危急文句用代码格式：도와주세요 (dowajuseyo)

① 112·119之后该存的号码 — "有麻烦就打1330"

受伤、起火或遭遇犯罪时，直接拨119·112。之后该存好的号码就是1330。旅行中让人慌张的时刻，大多数并不是因为危险，而是语言障碍——迷路时、把东西落在车上时、和店家语言不通时。1330是帮你降低这道障碍的旅游翻译·咨询窗口。只要记住"紧急情况拨119·112，遇到麻烦拨1330"，这篇文章的目的就达到了。

② 1330是什么 — 旅游热线档案

项目 内容
运营方 韩国观光公社 (VisitKorea / 한국관광공사)(KTO)旅游咨询·翻译热线
号码 无需区号，直接拨1330
时间 全年无休。俄语·越南语·泰语·马来/印尼语为08:00~19:00(其余语言的时段官方说明中没有)
语言 电话8种语言(韩语·英语·日语·中文·俄语·越南语·泰语·马来/印尼语)
费用 通过Wi-Fi拨打的网络语音通话免费
渠道 电话 + 短信聊天(仅限韩语·英语·日语·中文4种语言) — 1330 Messenger·KakaoTalk·Facebook·LINE·WhatsApp

③ 3个号码 — 什么时候打哪个

号码 负责范围 什么时候打
1330 旅游咨询·翻译·各种困难情况 不知道该按哪个号码，先打这个准没错
112 警察 犯罪·事故报案 — 自己直接拨
119 消防/急救 火灾·急症患者 — 自己直接拨
  • 紧急情况不要经过1330，直接拨119·112。先说位置，再简短说明情况，并且不要挂断电话(消防厅 (National Fire Agency / 소방청))。对于难以用语言报警的外国人等，119还受理短信·照片·视频报警(政策简报 (Policy Briefing / 정책브리핑))。
  • 1330是在非紧急的困难情况 — 路线·交通·失物·与店家沟通 — 下获得翻译和咨询的号码。

④ 用1330获得翻译 — 非紧急情况时

1330的价值在于翻译和咨询。通话顺序如下。

  1. 拨打1 ] [ 3 ] [ 3 ] [ 0 → 选择语言
  2. 用自己的语言说明情况("I left my bag in a taxi.")
  3. 接线员会告知该联系哪里、该说什么，并替你翻译需要说的话
  4. 和店员·出租车司机语言不通时，调成扬声器模式递过去，让接线员直接和对方说

1330能否直接与112·119三者通话连线，官方说明中未能确认(文化体育观光部 (MCST / 문화체육관광부)在2012年公布过加强1330与112·119联动的计划)。所以紧急情况请先自己直接拨119·112。

⑥ 拨号 — 画面原样记录

  • 无需区号，输入1 ] [ 3 ] [ 3 ] [ 0后按拨号键
  • 用韩国SIM卡或漫游套餐的话到这一步就结束了。如果是境外漫游状态连不上，加上国家代码，用+82-2-1330的格式重试
  • 还是不行的话，别再浪费时间反复尝试，直接请酒店前台代打电话是最快的办法(参考⑨)

⑦ 觉得打电话有压力的话 — 短信聊天

如果开口说话让人有压力，也可以不打电话，改用1330短信聊天。聊天只支持韩语·英语·日语·中文。靠打字说明情况，不用担心发音或周围噪音。紧急情况请不要用聊天，而是打电话给119·112 — 聊天更适合不紧急的咨询·翻译请求。

⑨ 慌张场景 — 实际会发生的事和应对

  1. 在急诊室但语言不通 — 只要拨通1330，用扬声器模式对着挂号窗口或医护人员就行。接线员会从症状说明到后续指引全程帮忙翻译。
  2. 警察来了但沟通不了 — 同样拨打1330，用扬声器模式和警察一起听。从报案受理到笔录陈述，接线员会在中间全程翻译。

这两种情况的关键都是：就算我不会韩语，流程也不会卡住。

⑩ 备用方案 — 连1330都不方便时

  • 酒店前台：很多情况下工作人员可以代打电话或帮忙说明情况。如果住处就在附近，这是最快的办法。
  • Papago翻译画面：把情况用英语输入，把翻译出来的画面直接给对方看的方法 — App安装参考#1230必备App指南。
