🎯 このマニュアルの読み方 — 表記のルール

韓国は安全な国ですが、覚えておくと安心できる番号がひとつあります。この記事はその番号ひとつに集中します。

  • ダイヤルボタンは角括弧: 1 ] [ 3 ] [ 3 ] [ 0
  • オペレーター・機関の案内文はかぎ括弧: 「Korea Travel Hotlineです」
  • 手で行う動作は太字: スピーカーフォンにして差し出す
  • そのまま見せる緊急フレーズはコード表記: トワジュセヨ (도와주세요)

① 通報番号より先に覚える番号 — 「困ったら1330」

警察(112)や消防(119)を覚える前に、この番号から先に保存しておきましょう: 1330。本当の問題は危険ではなく言葉の壁です — ケガをしたり物をなくしたりしたとき、韓国語で通報する方法がなくて慌ててしまうことがほとんどです。1330はその壁をなくしてくれる窓口です。「どんな状況でもとりあえず1330」とだけ覚えておけば、この記事の目的は達成されます。

② 1330とは何か — 観光ホットラインのプロフィール

項目 内容
運営 韓国観光公社(KTO)観光案内・通訳ホットライン
番号 市外局番なし 1330
時間 24時間年中無休
言語 韓国語 + 8外国語(英語・日本語・中国語・ロシア語・ベトナム語・タイ語・マレー語)
料金 無料(発信通話料のみ負担)
チャネル 電話 + リアルタイムチャット

③ 番号3種 — いつ何を押すか

番号 担当 いつ
1330 観光案内・通訳・困りごと全般 何を押せばいいか分からなければ、とにかくここから
112 警察 犯罪・紛失・事故通報 — 1330経由での接続も可能
119 消防/救急 火災・救急患者 — 1330経由での接続も可能
  • 112・119に直接かけても構いませんが、韓国語が通じないと対応が途切れやすくなります。1330を先に経由すれば通訳が付いたまま引き継がれます。

④ 核心機能 — 112/119 3者通訳ブリッジ

1330の本当の価値は案内ではなく、この機能にあります。通話を切らずにそのまま次の順番に従えば大丈夫です。

1. 1 ] [ 3 ] [ 3 ] [ 0 に発信 →「Korea Travel Hotlineです、どうされましたか?」(英語対応)

2. 英語で状況を説明します("My wallet was stolen near the subway station.")

3. オペレーターが判断し、112または119を3者通話で接続します — 電話を切らずそのまま待機

4. 警察・救急隊とオペレーターが韓国語で会話している間、オペレーターが自分には英語で通訳し続けます

5. 通報・出動受付が終わるまでオペレーターが通訳を維持してくれます

つまり自分は英語で話すだけで、通報の発信から通訳まですべてオペレーターが代わりに処理してくれます。

⑤ 状況別アルゴリズム — 何であれこの表から

状況 最優先の対応
体調が悪い(軽症: 風邪・頭痛など) まずは薬局・コンビニの常備薬から — 詳細は#1278 薬局利用ガイド
体調が悪い(重症: 高熱・ケガ・呼吸困難) 1330に電話 →「It's serious, I need a hospital」→119ブリッジを依頼
物をなくした 1330に電話 →112通報接続または遺失物センター案内を受ける
ぼったくり・不親切など旅行の不満 1330にそのまま受付 — 観光不便申告窓口の役割も果たします
道に迷った・予約がこじれた 通報するような状況でなくても構いません — 1330は日常的な通訳もサポートします

⑥ 電話のかけ方 — 画面そのまま

  • 市外局番なしで 1 ] [ 3 ] [ 3 ] [ 0 を入力後、通話ボタン
  • 韓国のSIM・ローミングならこれで完了です。海外ローミング状態でつながらない場合は国番号を付けて+82-2-1330の形でもう一度試してください
  • それでもだめなら、試すこと自体に時間を使わずホテルのフロントに電話代行を頼むのが一番早いです(⑨参照)

⑦ 電話がハードルに感じるなら — チャット

言葉で説明するのが負担なら、電話の代わりに1330リアルタイムチャットを利用しても構いません。状況を英語でタイピングする方式なので、発音や周囲の騒音を気にする必要がありません。ただし3者通訳ブリッジのようにすぐに112/119へつなぐ必要がある急ぎの状況なら電話のほうが速いです — チャットは急ぎでない問い合わせ・通訳依頼に優先して活用しましょう。

⑧ 緊急サバイバルフレーズ — Show-Me用

言葉が出てこなければ、この表をそのまま見せても構いません。スクリーンショットを撮って保存しておきましょう。

⑨ パニックシナリオ — 実際に起こることと対処法

1. 救急室なのに言葉が通じない — 受付窓口や医療スタッフに1330に電話をかけ、スピーカーフォンにして差し出せば大丈夫です。オペレーターが症状の説明から案内まで通訳してくれます。

2. 警察が来たのに意思疎通ができない — 同様に1330に電話し、スピーカーフォンにして警察と一緒に聞きます。通報受付から供述までオペレーターが間に入って通訳してくれます。

どちらの場合も、自分が韓国語を知らなくても手続きが止まらないことが核心です。

⑩ プランB — 1330もうまくいかないなら

  • ホテルのフロント: スタッフが代わりに電話をかけてくれたり、状況を説明してくれたりすることが多いです。宿泊先が近ければ一番早い方法です。
  • Papago翻訳画面: 状況を英語で入力し、翻訳された画面をそのまま見せる方法です — アプリのセットアップは#1230必須アプリガイド参照。
