TripAdvisor釜山论坛上，"10月想坐釜山→福冈的渡轮，要提前买票吗""卡美利亚号晕船严重吗""春节期间船还开吗""从邮轮码头怎么去釜山市区"这类问题从2024年一直问到2026年，日本一侧的社区里"博多港→釜山→KTX去首尔"这条动线的提问也持续到最近。可是网上还留着2024年底已经停运的高速船皇后甲壳虫 (Queen Beetle / 퀸비틀)的信息。这份手册只整理截至2026年9月实际仍在运营的船。

🏢 码头——釜山港国际客运码头

  • 码头正式名称是釜山港国际客运码头 (Busan Port International Passenger Terminal / 부산항 국제여객터미널)，地址是釜山东区忠壮大路206号。上面4条航线全部从这里出发(北港，釜山站后侧)。
  • 从釜山站 (Busan Station / 부산역)7号出口(后门)出来穿过忠壮大路，步行约15分钟。 行李箱大的话可以坐从釜山站后门·中央站 (Jungang Station / 중앙역)一带发车的码头接驳巴士(每20~30分钟一班，1130韩元)或打车(起步价距离)。
  • 地铁1号线的釜山站·中央站·草梁站 (Choryang Station / 초량역)都在步行范围内，但码头门口没有地铁站。
  • 码头里有免税店。换汇处·行李寄存·休息室规模都不大，建议先在市区换好钱(#435)再来。

🎫 预订·材料·截止办理时间

1. 预订：船公司直销(卡米利亚航运·关釜渡轮·泛星——有日语·英语页面)或国内外OTA(Trip.com、Klook、KKday等)。余票信息船公司直销更准确，OTA付款更方便。年末年初·黄金周·盂兰盆节期间4人间·特等舱最先售罄，这几个时段请提前一个月预订。

2. 材料：护照+入境日本需要Visit Japan Web二维码(渡轮·邮轮入境也支持)。回韩国走的入境流程和坐飞机一样(K-ETA·电子入境卡见#1396)——不要以为坐船就不一样，按飞机的标准准备。

3. 截止办理时间(最容易漏掉的一点)：新卡美利亚22:30出发的班次，建议18:00前抵达码头，19:00~19:30是办理·登船截止时间——开船前3小时柜台就会关闭。泛星是出发前2小时开始办理，提前1小时30分钟截止。

4. 抵达博多后：从博多港国际码头到博多站，坐西铁 (Nishitetsu / 니시테츠)巴士11·19·50·80路等，约20~25分钟，不需要走路换乘。

⚠ 4个容易踩的坑

1. 冬季玄界滩容易停航 — 浪高超过3米·风速超过14米/秒，停航风险就会上升。夜航客滚船比高速船更抗风浪，但遇到台风级天气还是会停开。停航的备选方案是釜山→福冈的航班，回程机票前请多留一天以上的余量。

2. 晕船 — 浪高1.5米以下基本感觉不到，超过这个高度的话，比起大通铺的地铺位置，低楼层·船体中部的舱房会更舒服。晕船药建议登船前30分钟服用。

3. 二等舱是榻榻米大通铺 — 想要独立空间就订4人间或特等舱。"便宜"的评论大多说的是二等舱。

4. 陈旧信息要小心 — 提到皇后甲壳虫(已停运)或泛星梦想号(已退役)的评论·博客，时间和票价全部作废。只参考2025年以后的信息。

🚢 坐邮轮抵达釜山——码头分两处

  • 分流原则：能从釜山港大桥 (Busan Harbor Bridge / 부산항대교)桥下通过的中小型邮轮，停靠在桥内侧的北港国际客运码头 (North Port International Passenger Terminal / 북항 국제여객터미널)(地址同上，步行可达釜山站)；无法通过的大型·超大型邮轮，停靠在桥外侧的影岛国际邮轮码头 (Yeongdo International Cruise Terminal / 영도 국제크루즈터미널)(地址：Haeyang-ro 301beon-gil 17, Yeongdo-gu, Dongsam-dong)。请先确认船公司通知里写的码头名称。
  • 影岛码头→市区：釜山站前坐101·88路公交车→在东三交叉路口 (Dongsam Intersection / 동삼교차로)下车→步行约15分钟(反方向同一条线路)。时间紧张就打车(到釜山站·南浦洞约20~30分钟)。入港当天有时会开专线接驳车，请到码头问讯处当天确认。
  • 2026年的规模：据釜山港湾公社 (Busan Port Authority / 부산항만공사，BPA)统计，仅2026年上半年就有219个航次·32万人次——下船高峰期打车排队会很长。叫Kakao T(#1273)会更快。
  • 半日组合：甘川文化村 (Gamcheon Culture Village / 감천문화마을)(#1024)→札嘎其市场 (Jagalchi Market / 자갈치시장)·国际市场(#1022)→有时间的话再去海云台 (Haeundae / 해운대)(#1023)。没有官方"标准路线"，这个组合是最常见的走法。现金只用于市场摊位的小额消费，其余用卡(#435)。

⚙ FAQ 3条

1. 真的没有当天往返福冈的船了吗? — 没有了(截至2026年9月)。要么坐夜航睡一觉过去，要么把白天那班(博多12:30出发→18:30抵达釜山)反向使用。

2. 坐船去日本，K-ETA·入境手续会不一样吗? — 官方信息里没有查到海上入境的例外规定。按和坐飞机一样的标准准备最保险(#1396)。

3. 邮轮停靠8小时能去首尔吗? — 不行(KTX往返就要5小时)。行程留在釜山市内，只有停靠12小时以上时才考虑去庆州(#1115)。
