🎯 このマニュアルの読み方 — 表記のルール

韓国は安全な国ですが、覚えておくと安心できる番号がひとつあります。この記事はその番号ひとつに集中します。

  • ダイヤルボタンは角括弧: 1 ] [ 3 ] [ 3 ] [ 0
  • オペレーター・機関の案内文はかぎ括弧: 「Korea Travel Hotlineです」
  • 手で行う動作は太字: スピーカーフォンにして差し出す
  • そのまま見せる緊急フレーズはコード表記: トワジュセヨ (도와주세요)

① 112・119の次に保存する番号 — 「困ったら1330」

ケガをしたり、火事が起きたり、犯罪に遭ったりしたら、119・112にすぐかけます。その次に保存しておく番号が1330です。旅行中に慌てる場面の多くは、危険ではなく言葉の壁が原因です — 道に迷ったとき、物を置き忘れて降りたとき、お店で言葉が通じないとき。1330はその壁を低くしてくれる観光通訳・案内窓口です。「緊急は119・112、困ったら1330」とだけ覚えておけば、この記事の目的は達成されます。

② 1330とは何か — 観光ホットラインのプロフィール

項目 内容
運営 韓国観光公社 (韓国観光公社 / 한국관광공사、KTO) 観光案内・通訳ホットライン
番号 市外局番なし 1330
時間 年中無休。ロシア語・ベトナム語・タイ語・マレー/インドネシア語は08:00~19:00(その他の言語の時間帯は公式案内に記載なし)
言語 電話は8言語(韓国語・英語・日本語・中国語・ロシア語・ベトナム語・タイ語・マレー/インドネシア語)
料金 Wi-Fiでかけるインターネット音声通話は無料
チャネル 電話 + テキストチャット(韓国語・英語・日本語・中国語の4言語のみ) — 1330メッセンジャー・カカオトーク・Facebook・LINE・WhatsApp

③ 番号3種 — いつ何を押すか

番号 担当 いつ
1330 観光案内・通訳・困りごと全般 何を押せばいいか分からなければ、とにかくここから
112 警察 犯罪・事故通報 — 直接かける
119 消防/救急 火災・救急患者 — 直接かける
  • 緊急なら1330を経由せず、119・112にすぐかけます。場所 → 状況の順に短く伝え、電話を切りません(消防庁 / 소방청)。119は、言葉での通報が難しい外国人などのためにテキスト・写真・動画での通報も受け付けています(政策ブリーフィング / 정책브리핑)。
  • 1330は緊急ではない困った状況 — 道・交通・紛失・お店との意思疎通 — で通訳と案内を受けられる番号です。

④ 1330で通訳してもらう — 緊急ではないとき

1330の強みは通訳と案内です。通話の流れは次のとおりです。

  1. 1 ] [ 3 ] [ 3 ] [ 0 に発信 → 言語を選ぶ
  2. 自分の言語で状況を説明する("I left my bag in a taxi.")
  3. オペレーターが、どこに連絡すればよいか、何を伝えればよいかを案内し、必要な言葉を通訳してくれる
  4. お店のスタッフやタクシー運転手と言葉が通じなければ、スピーカーフォンにして渡し、オペレーターに直接話してもらう

1330が112・119と3者通話で直接つないでくれるかどうかは、公式案内では確認できませんでした(文化体育観光部は2012年に、1330と112・119の連携強化計画を発表しています)。そのため緊急なら119・112に先に直接かけます。

⑤ 状況別アルゴリズム — 何であれこの表から

状況 最優先の対応
体調が悪い(軽症: 風邪・頭痛など) まずは薬局・コンビニの常備薬から — 詳細は#1278 薬局利用ガイド
体調が悪い(重症: 高熱・ケガ・呼吸困難) 119にすぐ電話 — 場所と症状を短く伝え、電話を切らない
物をなくした 乗った交通機関の遺失物センター — 連絡先が分からなければ1330で案内を受ける(詳細は#1392 遺失物マニュアル)
ぼったくり・不親切など旅行の不満 1330にそのまま受付 — 観光不便申告窓口の役割も果たします
道に迷った・予約がこじれた 通報するような状況でなくても構いません — 1330は日常的な通訳もサポートします

⑥ 電話のかけ方 — 画面そのまま

  • 市外局番なしで 1 ] [ 3 ] [ 3 ] [ 0 を入力後、通話ボタン
  • 韓国のSIM・ローミングならこれで完了です。海外ローミング状態でつながらない場合は国番号を付けて+82-2-1330の形でもう一度試してください
  • それでもだめなら、試すこと自体に時間を使わずホテルのフロントに電話代行を頼むのが一番早いです(⑨参照)

⑦ 電話がハードルに感じるなら — チャット

言葉で説明するのが負担なら、電話の代わりに1330テキストチャットを利用しても構いません。チャットは韓国語・英語・日本語・中国語のみです。状況をタイピングする方式なので、発音や周囲の騒音を気にする必要がありません。急ぎの状況ならチャットではなく119・112に電話します — チャットは急ぎでない問い合わせ・通訳依頼に使いましょう。

⑨ パニックシナリオ — 実際に起こることと対処法

  1. 救急室なのに言葉が通じない — 受付窓口や医療スタッフに1330に電話をかけ、スピーカーフォンにして差し出せば大丈夫です。オペレーターが症状の説明から案内まで通訳してくれます。
  2. 警察が来たのに意思疎通ができない — 同様に1330に電話し、スピーカーフォンにして警察と一緒に聞きます。通報受付から供述までオペレーターが間に入って通訳してくれます。

どちらの場合も、自分が韓国語を知らなくても手続きが止まらないことが核心です。

⑩ プランB — 1330もうまくいかないなら

  • ホテルのフロント: スタッフが代わりに電話をかけてくれたり、状況を説明してくれたりすることが多いです。宿泊先が近ければ一番早い方法です。
  • Papago翻訳画面: 状況を英語で入力し、翻訳された画面をそのまま見せる方法です — アプリのセットアップは#1230必須アプリガイド参照。
