🎯 이 매뉴얼을 읽는 법 — 표기 규약

한국은 안전한 나라지만, 알아두면 마음이 놓이는 번호 하나가 있다. 이 글은 그 번호 하나에만 집중한다.

  • 다이얼 버튼은 대괄호: 1 ] [ 3 ] [ 3 ] [ 0
  • 상담원·기관의 안내 문구는 낫표: 「Korea Travel Hotline입니다」
  • 손으로 하는 동작은 굵게: 스피커폰으로 놓고 건네기
  • 그대로 보여줄 위급 문구는 코드: 도와주세요 (dowajuseyo)

① 신고 번호보다 먼저 외울 번호 — "곤란하면 1330"

경찰(112)이나 소방(119)을 외우기 전에 이 번호부터 저장하자: 1330. 진짜 문제는 위험이 아니라 언어 장벽이다 — 다치거나 물건을 잃어버렸을 때 한국어로 신고할 방법이 없어서 당황하는 것이 대부분이다. 1330은 그 장벽을 없애 주는 창구다. "무슨 상황이든 일단 1330"이라고만 기억해도 이 글의 목적은 끝난다.

② 1330이 뭔가 — 관광 핫라인 프로필

항목 내용
운영 한국관광공사(KTO) 관광 안내·통역 핫라인
번호 국번 없이 1330
시간 24시간 연중무휴
언어 한국어 + 8개 외국어 (영어·일본어·중국어·러시아어·베트남어·태국어·말레이어)
요금 무료 (발신 통화료만 부담)
채널 전화 + 실시간 문자 채팅

③ 번호 3종 — 언제 뭘 누르나

번호 담당 언제
1330 관광 안내·통역·곤란 상황 전반 뭘 눌러야 할지 모르겠으면 무조건 여기부터
112 경찰 범죄·분실·사고 신고 — 1330을 거쳐 연결도 가능
119 소방/구급 화재·응급 환자 — 1330을 거쳐 연결도 가능
  • 112·119에 직접 걸어도 되지만, 한국어가 안 통하면 상담이 끊기기 쉽다. 1330을 먼저 거치면 통역이 붙은 채로 넘어간다.

④ 핵심 기능 — 112/119 3자 통역 브릿지

1330의 진짜 가치는 안내가 아니라 이 기능이다. 통화를 끊지 않고 그대로 다음 순서를 따라가면 된다.

1. 1 ] [ 3 ] [ 3 ] [ 0 통화 → 「Korea Travel Hotline입니다, 무엇을 도와드릴까요?」(영어 응대)

2. 영어로 상황을 설명 ("My wallet was stolen near the subway station.")

3. 상담원이 판단해 112 또는 119를 3자 통화로 연결 — 전화를 끊지 말고 그대로 대기

4. 경찰·구급대와 상담원이 한국어로 대화하는 동안, 상담원이 나에게는 영어로 계속 통역

5. 신고·출동 접수가 끝날 때까지 상담원이 통역을 유지해 준다

즉 나는 영어로 말하기만 하면, 신고 전화를 거는 것부터 통역까지 상담원이 대신 처리한다.

⑤ 상황별 알고리즘 — 뭐가 됐든 이 표부터

상황 1순위 대응
몸이 아프다 (경증: 감기·두통 등) 약국·편의점 상비약부터 — 상세는 #1278 약국 이용 가이드
몸이 아프다 (심함: 고열·부상·호흡곤란) 1330 전화 → "It's serious, I need a hospital" → 119 브릿지 요청
물건을 잃어버렸다 1330 전화 → 112 신고 연결 또는 유실물센터 안내 받기
바가지·불친절 등 여행 불만 1330에 그대로 접수 — 관광 불편 신고 창구 역할도 한다
길을 잃었다·예약이 꼬였다 신고 상황이 아니어도 된다 — 1330은 일상 통역도 지원한다

⑥ 전화 걸기 — 화면 그대로

  • 국번 없이 1 ] [ 3 ] [ 3 ] [ 0 입력 후 통화 버튼
  • 한국 유심·로밍이면 이대로 끝. 해외 로밍 상태라 연결이 안 되면 국가번호를 붙여 +82-2-1330 형태로 다시 시도
  • 그래도 안 되면 시도 자체에 시간을 쓰지 말고 호텔 프런트에 전화 대행을 부탁하는 게 가장 빠르다 (⑨ 참고)

⑦ 전화가 부담스럽다면 — 문자 채팅

말로 설명하는 게 부담스러우면 전화 대신 1330 실시간 문자 채팅을 이용해도 된다. 상황을 영어로 타이핑하는 방식이라 발음이나 주변 소음 걱정이 없다. 다만 3자 통역 브릿지처럼 즉시 112/119로 연결이 필요한 급한 상황이면 전화가 더 빠르다 — 채팅은 급하지 않은 문의·통역 요청에 우선 활용하자.

⑧ 위급 생존 문구 — Show-Me용

말이 안 나오면 이 표를 그대로 보여줘도 된다. 스크린샷 찍어 저장해 두자.

⑨ 당황 시나리오 — 실제로 벌어지는 일과 대처

1. 응급실인데 말이 안 통한다 — 접수창구나 의료진에게 1330에 전화를 걸어 스피커폰으로 내밀면 된다. 상담원이 증상 설명부터 안내까지 통역해 준다.

2. 경찰이 왔는데 소통이 안 된다 — 마찬가지로 1330에 전화해 스피커폰으로 경찰과 함께 듣는다. 신고 접수부터 진술까지 상담원이 중간에서 통역해 준다.

두 경우 다 내가 한국어를 몰라도 절차가 멈추지 않는다는 게 핵심이다.

⑩ 플랜B — 1330도 여의치 않다면

  • 호텔 프런트: 직원이 대신 전화해 주거나 상황을 설명해 주는 경우가 많다. 숙소가 가깝다면 가장 빠른 방법.
  • 파파고 번역 화면: 상황을 영어로 입력해 번역된 화면을 그대로 보여주는 방법 — 앱 셋업은 #1230 필수 앱 가이드 참고.
