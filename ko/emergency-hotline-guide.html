🎯 이 매뉴얼을 읽는 법 — 표기 규약

한국은 안전한 나라지만, 알아두면 마음이 놓이는 번호 하나가 있다. 이 글은 그 번호 하나에만 집중한다.

  • 다이얼 버튼은 대괄호: 1 ] [ 3 ] [ 3 ] [ 0
  • 상담원·기관의 안내 문구는 낫표: 「Korea Travel Hotline입니다」
  • 손으로 하는 동작은 굵게: 스피커폰으로 놓고 건네기
  • 그대로 보여줄 위급 문구는 코드: 도와주세요 (dowajuseyo)

① 112·119 다음으로 저장할 번호 — "곤란하면 1330"

다치거나 불이 나거나 범죄를 당했다면 119·112에 바로 건다. 그다음으로 저장해 둘 번호가 1330이다. 여행 중 당황하는 순간 대부분은 위험이 아니라 언어 장벽에서 온다 — 길을 잃었을 때, 물건을 두고 내렸을 때, 가게에서 말이 안 통할 때. 1330은 그 장벽을 낮춰 주는 관광 통역·안내 창구다. "응급은 119·112, 곤란하면 1330"이라고만 기억해도 이 글의 목적은 끝난다.

② 1330이 뭔가 — 관광 핫라인 프로필

항목 내용
운영 한국관광공사(KTO) 관광 안내·통역 핫라인
번호 국번 없이 1330
시간 연중무휴. 러시아어·베트남어·태국어·말레이/인도네시아어는 08:00~19:00 (나머지 언어의 시간대는 공식 안내문에 없음)
언어 전화 8개 언어 (한국어·영어·일본어·중국어·러시아어·베트남어·태국어·말레이/인도네시아어)
요금 와이파이로 거는 인터넷 음성통화는 무료
채널 전화 + 문자 채팅(한국어·영어·일본어·중국어 4개 언어만) — 1330 메신저·카카오톡·페이스북·라인·왓츠앱

③ 번호 3종 — 언제 뭘 누르나

번호 담당 언제
1330 관광 안내·통역·곤란 상황 전반 뭘 눌러야 할지 모르겠으면 무조건 여기부터
112 경찰 범죄·사고 신고 — 직접 건다
119 소방/구급 화재·응급 환자 — 직접 건다
  • 응급이면 1330을 거치지 말고 119·112에 바로 건다. 위치 → 상황 순으로 짧게 말하고 전화를 끊지 않는다(소방청). 119는 말로 신고하기 어려운 외국인 등을 위해 문자·사진·영상 신고도 받는다(정책브리핑).
  • 1330은 응급이 아닌 곤란한 상황 — 길·교통·분실·가게와의 의사소통 — 에서 통역과 안내를 받는 번호다.

④ 1330으로 통역 받기 — 응급이 아닐 때

1330의 쓸모는 통역과 안내다. 통화 순서는 이렇다.

1. 1 ] [ 3 ] [ 3 ] [ 0 통화 → 언어를 고른다

2. 내 언어로 상황을 설명 ("I left my bag in a taxi.")

3. 상담원이 어디에 연락해야 하는지, 무엇을 말하면 되는지 안내하고 필요한 말을 통역해 준다

4. 가게 직원·택시 기사와 말이 안 통하면 스피커폰으로 놓고 건네 상담원이 직접 말하게 한다

1330이 112·119와 3자 통화로 바로 이어 주는지는 공식 안내에서 확인하지 못했다(문화체육관광부는 2012년 1330과 112·119의 연계 강화 계획을 발표했다). 그래서 응급이면 119·112에 먼저 직접 건다.

⑤ 상황별 알고리즘 — 뭐가 됐든 이 표부터

상황 1순위 대응
몸이 아프다 (경증: 감기·두통 등) 약국·편의점 상비약부터 — 상세는 #1278 약국 이용 가이드
몸이 아프다 (심함: 고열·부상·호흡곤란) 119에 바로 — 위치와 증상을 짧게, 전화를 끊지 않는다
물건을 잃어버렸다 탄 교통수단의 유실물센터 — 어디에 연락할지 모르면 1330 안내 받기 (상세는 #1392 분실물 매뉴얼)
바가지·불친절 등 여행 불만 1330에 그대로 접수 — 관광 불편 신고 창구 역할도 한다
길을 잃었다·예약이 꼬였다 신고 상황이 아니어도 된다 — 1330은 일상 통역도 지원한다

⑥ 전화 걸기 — 화면 그대로

  • 국번 없이 1 ] [ 3 ] [ 3 ] [ 0 입력 후 통화 버튼
  • 한국 유심·로밍이면 이대로 끝. 해외 로밍 상태라 연결이 안 되면 국가번호를 붙여 +82-2-1330 형태로 다시 시도
  • 그래도 안 되면 시도 자체에 시간을 쓰지 말고 호텔 프런트에 전화 대행을 부탁하는 게 가장 빠르다 (⑨ 참고)

⑦ 전화가 부담스럽다면 — 문자 채팅

말로 설명하는 게 부담스러우면 전화 대신 1330 문자 채팅을 이용해도 된다. 채팅은 한국어·영어·일본어·중국어로만 된다. 상황을 타이핑하는 방식이라 발음이나 주변 소음 걱정이 없다. 급한 상황이면 채팅이 아니라 119·112에 전화한다 — 채팅은 급하지 않은 문의·통역 요청에 쓰자.

⑧ 위급 생존 문구 — Show-Me용

말이 안 나오면 이 표를 그대로 보여줘도 된다. 스크린샷 찍어 저장해 두자.

상황 보여줄 문구

아플 때 아파요 (apayo)
물건을 잃어버렸을 때 잃어버렸어요 (ireobeoryeosseoyo)

통역이 필요할 때 통역 도와주세요 (tongyeok dowajuseyo)

⑨ 당황 시나리오 — 실제로 벌어지는 일과 대처

1. 응급실인데 말이 안 통한다 — 접수창구나 의료진에게 1330에 전화를 걸어 스피커폰으로 내밀면 된다. 상담원이 증상 설명부터 안내까지 통역해 준다.

2. 경찰이 왔는데 소통이 안 된다 — 마찬가지로 1330에 전화해 스피커폰으로 경찰과 함께 듣는다. 신고 접수부터 진술까지 상담원이 중간에서 통역해 준다.

두 경우 다 내가 한국어를 몰라도 절차가 멈추지 않는다는 게 핵심이다.

⑩ 플랜B — 1330도 여의치 않다면

  • 호텔 프런트: 직원이 대신 전화해 주거나 상황을 설명해 주는 경우가 많다. 숙소가 가깝다면 가장 빠른 방법.
  • 파파고 번역 화면: 상황을 영어로 입력해 번역된 화면을 그대로 보여주는 방법 — 앱 셋업은 #1230 필수 앱 가이드 참고.
